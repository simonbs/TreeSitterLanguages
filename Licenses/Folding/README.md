# Folding query notices

The files in this directory accompany the pinned inputs recorded in
`FoldingQueries/sources.json`. They include the MIT notices for the eight
grammar-hosted query sources and the Apache-2.0 license for nvim-treesitter.
Inherited query sections retain the license of their own source repository.

The original queries are retained in `FoldingQueries/Upstream`. Generated queries
identify source URLs and state that inheritance was expanded for Runestone.
Markdown's additional adaptation is documented in `FOLDING_QUERIES.md`.
